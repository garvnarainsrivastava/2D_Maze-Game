# 🧩 Maze Runner

A simple maze game made with **Python and Turtle**.

Move the player through the maze, collect treasures, and avoid the enemies. Each treasure gives you **100 points**.

## 🎮 Controls

* ⬆️ Up — Move up
* ⬇️ Down — Move down
* ⬅️ Left — Move left
* ➡️ Right — Move right

## 🚀 Run the Game

Make sure Python 3 is installed, then run:

```bash
python maze_runner.py
```

No extra libraries are needed.

## 🛠️ Built With

* Python
* Turtle
* Random

## 📌 Note

The maze, treasures, and enemies can be customized by editing the `MAP` in the Python file.

Have fun playing! 🎮
